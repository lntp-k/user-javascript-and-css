# ADR 0001 — Chrome용 CSS 적용 범위와 폰트 보존

날짜: 2026-10-02. 상태: 적용됨.

## 배경

원본은 모든 사이트에 적용하는 사용자 CSS와 Claude 전용 CSS였다. Chrome 154에서 원본의 `@-moz-document` 래퍼는 파싱된 규칙 0개를 만들었다. 래퍼를 제거하면 모든 span의 폰트와 색상을 강제하는 규칙이 코드·수식·카드·오류 표시를 덮어쓰는 문제가 재현됐다.

## 결정

- 확장 프로그램이 URL 매칭을 담당하고, 배포 CSS는 Chrome이 직접 파싱할 수 있는 일반 CSS로 저장한다.
- 일반 본문은 상속과 제한된 의미 요소 선택자로 적용한다. 모든 div/span에 대한 일괄 강제 규칙은 사용하지 않는다.
- 코드와 구문 강조 자손은 고정폭 폰트 목록을 사용한다. 알려진 수식·에디터·아이콘·명시적 폰트 영역은 강제 규칙에서 제외한다.
- 글자색, 배경색, 굵기 축, 헤딩 크기, 입력 UI 크기와 애니메이션을 전역 변경하지 않는다.
- 읽기 컨테이너의 문단·목록에만 `1.125rem`과 줄 간격 `1.7`을 적용한다. 설치된 일반 Pretendard도 대체 목록에 넣고 외부 폰트는 요청하지 않는다.
- 원본/수정본 측정은 사용자 프로필과 분리된 설치 Chrome에서 수행한다. 사이트 접근 제한을 우회하지 않는다.

## 결과와 제한

수정본 Chrome 테스트 240개, MDN 160개, KaTeX 416개 검사가 통과했다. 실제 KaTeX 요소 100개의 폰트가 유지됐다. CSS만으로 임의 사이트의 원래 폰트를 모두 판별하지는 못한다. Shadow DOM과 iframe, 알려지지 않은 아이콘/serif 클래스에는 별도 검토가 필요하다.

Claude 공개 페이지는 HTTP 403이었다. Claude 전용 CSS의 로컬 테스트 결과와 실제 로그인된 대화 화면의 검증을 구분한다. 확장 프로그램 설치와 URL 매칭은 아직 검증하지 않았다.
