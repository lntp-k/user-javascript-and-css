# ADR 0002 — 인라인 font 축약 지정 보호

날짜: 2026-10-02. 상태: 적용됨. ADR 0001의 폰트 보호 결정을 보완한다.

독립 Codex Sol 리뷰에서 `<p style="font: italic 20px Georgia">`가 본문 폰트와 18px로 덮어써지는 문제가 Chrome에서 재현됐다. `font-family` 부분 문자열만 검사하면 동등한 `font:` 축약 지정은 보호할 수 없기 때문이다.

v2.0.1은 `[style*="font" i]`와 그 자손을 강제 규칙에서 제외한다. CSS 속성 선택자로 선언을 완전히 파싱할 수 없으므로, 공백 변형을 빠뜨리지 않도록 보수적으로 제외한다. 그 결과 `font-weight`·`font-size` 지정이나 다른 값의 `font` 문자열도 제외될 수 있다. 사이트가 명시한 서식을 존중하는 쪽을 선택했다.

축약 지정 및 자손의 폰트·크기·줄 간격을 회귀 테스트하고, contenteditable·인라인 수식 검사를 추가했다. 테스트의 원본 비교 입력은 배포에서 제외되는 로컬 백업 대신 Git에 포함되는 고정 CSS fixture로 이동했다.

버전: v2.0.1. 최종 검사: 로컬 320개, MDN 162개, KaTeX 417개, 총 899개 통과. Claude 실제 화면은 앞서 관찰한 HTTP 403으로 미검증이다.
